# Question annotation guidelines

Use these guides to judge whether questions are clear and useful, and whether the provided text supports their answers. Each guide presents an example document first, then explains eight checks in plain language, with each criterion name in parentheses after its heading. Each criterion paragraph starts with a definition, followed by judging and scoring instructions. Every check has a good and a bad question–answer example, each with a suggested score and a short explanation for that check. The scoring scale remains 1–5. Page 4 checks understanding of the guideline: answer 10 single-choice questions about the annotation task and scoring instructions, each with four options and one correct answer. Submit the test for review before beginning annotation.
